# Hermes Skills

This directory contains the Hermes Skills Hub package for OP3 Code Sentinel:

```text
skills/op3-code-sentinel/
```

Hermes tap discovery expects installable skills under:

```text
skills/<skill-name>/SKILL.md
```

Install with:

```bash
hermes skills install op3-221/op3-code-sentinel-skill/skills/op3-code-sentinel
```

See `../HERMES.md` for the full Hermes install notes.
